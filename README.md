FERROLINE — a round-based tactical FPS in three.js. Vanguard (you + 2 ally bots) vs Wardens (4 defender bots) on a derelict rail-foundry yard: two bomb sites, plant/defuse, economy + buy menu, three guns, a frag grenade, and bot AI that walks waypoints, holds lanes, and reacts to sight and sound. Offline single-player, no network.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080.
